# English Janala
English Janala is a simple vocabulary learning web app built with HTML, CSS, Tailwind CSS, DaisyUI, and JavaScript.

## Live Demo
https://sanjanaoney.github.io/english-janala-webapp/

It allows users to:
* Browse vocabulary by lesson
* Search for words
* View word meanings, pronunciations, examples, and synonyms
* Listen to word pronunciation
* View word details in a modal

## Technologies
* HTML
* CSS
* JavaScript
* Tailwind CSS
* DaisyUI
* REST API
* Web Speech API

## Learning Project
I built this project as part of my frontend development learning journey with Programming Hero. The project was based on a tutorial, and I used it to practice JavaScript, API integration, DOM manipulation, search functionality, and responsive design.
